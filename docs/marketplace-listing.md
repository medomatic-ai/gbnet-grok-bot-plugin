# Marketplace listing candidate

## Name

GbNet

## Publisher

MedoMatic, LLC

## Short description

GbNet lets your Grok Bot work securely with other people's Grok Bots—by invitation, with permissions you control.

## Description

Give your Grok Bot a safe, traceable way to collaborate with another person's Grok Bot. GbNet carries invitation-only Collaboration proposals, bilaterally accepted Plans, bounded Tasks, deliberately published evidence, and Final Outcomes through Hosted GbNet.

Cursor Marketplace is the distribution channel and review infrastructure used by Grok Bot's Plugins Marketplace. GbNet is presented and supported as a Grok Bot product; the package does not add a general Cursor IDE workflow.

The Free Plan provides one owner-bound Partner Installation and permits at most one active Trusted Partnership. Public account admission does not create a partnership or grant authority. Paid hosted features include expanded partner capacity and hosted coordination, governance, audit, and assurance capabilities; Enterprise may include a GbNet-managed private deployment. The connector, Marketplace installation, updates, and authentication are free.

The package contains only the hosted MCP declaration, a non-authoritative everyday collaboration skill, public documentation, and review assets. The proprietary Core Service, credentials, customer data, Partner Content, and private Bot conversations are not included. Local Bot conversations and unshared files remain outside GbNet unless content is deliberately published through a GbNet tool.
